MD5 CRYPTOGRAPHY LAB

Simulasi Perhitungan Algoritma Message Digest 5

01. Input Pesan

02. Hasil Message Digest

Pesan asli:

abc

Hasil MD5:

900150983cd24fb0d6963f7d28e17f72

Panjang hash: 128 bit / 32 karakter hexadecimal.

03. Konversi ASCII ke Biner

Setiap karakter diubah menjadi kode ASCII dan direpresentasikan dalam 8 bit biner.

04. Penambahan Bit Pengganjal (Padding)

MD5 menambahkan bit 1 diikuti bit 0 sampai panjang pesan mencapai 448 modulo 512. 










    

        
05. Penambahan Panjang Pesan


        

            Menambahkan 64 bit yang menyatakan panjang
            pesan asli.
        

    


    


    









    

        
06. Pengolahan Pesan dalam Blok 512 Bit


        

            Pesan dibagi menjadi blok 512 bit,
            kemudian setiap blok dibagi menjadi
            16 bagian berukuran 32 bit.
        

    


    


    









    

        
07. Inisialisasi Buffer MD5


        

            MD5 menggunakan empat buffer dengan
            ukuran masing-masing 32 bit.
        

    


    









    

        
08. Pengolahan 64 Putaran MD5


        

            MD5 menggunakan empat fungsi logika
            yang diproses dalam empat ronde.
        

    


    


    

        Seluruh 64 putaran dijalankan oleh library CryptoJS.
        Bagian ini menampilkan struktur dan contoh
        perhitungan putaran pertama.
